FM-1 Clock

Firmware for the M-VAVE FM-1: a pendulum wall clock and a cuckoo clock.

⚠ Not yet tried on a real FM-1. FM-1 Clock is built and tested on every change, in CI and in the FM-1 emulator, but it has not been tried on an actual device. Install it at your own risk.

One day the FM-1 may be an almost forgotten treasure, so here is something that looks completely useless now and may turn out to be its only useful function: a clock. Its bell is a real 31-day pendulum clock's coil gong, taken apart into 742 ringing modes and rebuilt as FM synthesis. Turn ALGORITHM and a cuckoo clock carved in walnut calls the hours instead, its bird on two FM pipes over a wire gong. Both hang on the same panel wall.

742modes of a real gong, each an FM carrier
~400FM operators running every frame
2clocks, one time, kept by the crystal
0samples: every sound is synthesised

Install

  1. Open this page in Chrome or Edge on a computer (they can talk to the FM-1 over USB MIDI).
  2. Connect the FM-1 directly to the computer with a USB data cable, and switch it on.
  3. Close other apps that use MIDI, press Install and allow MIDI when the browser asks.

Log

  

  
Do not unplug the cable while it writes (about a minute). If an install is cut off, the FM-1
    stays in update mode: replug it and press Install again, and it finishes. If the FM-1 does not start at all, hold
    OCT− while switching it on: it starts in the USB rescue, where an installer always works. To go back to
    the official firmware, use M-VAVE's own updater M-UPGRADE. Installing firmware is at your own risk.


  
Using it

  

    
ALGORITHMThe wall clock or the cuckoo clock.

    
SELECT / PRESETSThe minute and the hour hand. Turned forward past the hour, it strikes it, as a real clock does.

    
PLAYStrikes (or calls) the last hour again.

    
FXThe strike on or off.

    
GLOThe keys' lights: they follow the pendulum, flash the hours, or stay off.

    
ENVWinds the cuckoo clock.

    
KNOB 1 / 2The ticks' and the strike's levels.

  

  
The FM-1 has no battery-backed clock: it starts at 10:10 and forgets the
    time when switched off. Set it with the hands, or send the computer's time over MIDI
    (CC 20, 21, 22: hours, minutes, seconds) with tools/settime.py from the source:

  
pip3 install mido python-rtmidi
python3 tools/settime.py
